# 季茹意 · 个人展示平台

上海杉达学院 · 计算机科学与技术专业 · 来自上海

一个纯静态、零依赖的个人作品集网站，用于展示我的计算机能力与我做过的项目。

## 内容板块

- **关于我**：个人简介与学校 / 专业 / 城市 / 方向速览
- **能力**：编程基础、移动开发（HarmonyOS）、前端与界面、后端与数据库、数据与可视化、团队协作
- **项目展示**：可分类筛选的项目卡片（移动开发 / Web / 课程），目前收录「邻安 · 鸿蒙简易 App」等
- **联系我**：邮箱、电话与 GitHub

## 技术栈

- 纯 HTML / CSS / JavaScript，无构建步骤，无第三方依赖
- 支持明暗主题切换、滚动浮现动画、卡片筛选
- 占位图为内联 SVG，离线也可正常显示

## 本地预览

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 目录结构

```
index.html              页面结构
assets/css/styles.css   样式
assets/js/main.js       交互逻辑
assets/img/             图片资源
gen_placeholders.py     占位图生成脚本
```

## 部署

可直接托管到 GitHub Pages、任意静态空间或云服务器。
